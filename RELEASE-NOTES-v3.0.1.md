# BlueGate v3.0.1 — Catalog Tile Refinement

- Rebalanced catalog cards to a reference-style image-heavy ratio (roughly 70–75% visual / 25–30% text).
- Product logos now use contain sizing with additional breathing room so square logos remain fully visible.
- Card body now shows only product name and price; plan descriptions were removed from the card surface.
- Discount badges stay compact. When a variant discount is shown, the card price is tied to that discounted variant to avoid misleading users.
- Web generic product cards received the same simplified card language; the whole card opens product details.
