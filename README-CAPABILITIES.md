# BlueGate Core capability metadata · v2.1.6

This release exposes machine-readable metadata for License Control v2.4+:

- `manifest/capabilities.json` describes features physically included in Free Core.
- `manifest/installer-schema.json` describes every installer input shown by the Telegram License Bot.

The metadata is descriptive only; license enforcement still occurs in the signed entitlement runtime. Pro-only implementations remain outside Free Core.
